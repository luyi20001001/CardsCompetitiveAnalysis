# 信用卡競品比較產生器

## 運作方式

```
Google 試算表（卡片、官網、活動網址、附加權益網址）
        │  網站每次載入時讀取（快取 60 秒）
        ▼
Cloudflare Worker ── 按下「確定產生」時直接讀取官方網址 → 內建爬蟲整理成比較表與 3 大洞察
        │
        ▼
Cloudflare KV（CardsCompetitiveAnalysis）── 存網站文字、試算表設定、管理者密碼、缺漏紀錄、網頁快取
```

- **只要維護 Google 試算表**：新增卡片、修改網址都在試算表做，網站約 1 分鐘內自動更新。
- 不需要 Supabase、不需要任何金鑰或密碼設定。
- 管理者預設密碼 **1234**，登入後可在後台修改。

## Google 試算表格式

試算表要設為「**知道連結的任何人都能檢視**」（共用 → 一般存取權）。

每家銀行兩個分頁，分頁名稱要和後台「資料來源」設定的一致：

| 分頁 | 必要欄位（第一列表頭） |
| --- | --- |
| 卡片分頁（例：富邦） | 卡片名稱、官網；選填：主力/非主力、特色、類型、銀行卡/聯名卡、活動網址 |
| 附加權益分頁（例：富邦-附加權益） | 主題、網址 |

附加權益的「主題」需使用這些名稱：附加權益首頁、機場接送、機場貴賓室、機場外圍停車、市區停車、道路救援、高爾夫球、高鐵購票、旅遊平安險、旅遊不便險。

新增一家銀行：在試算表新增兩個分頁 → 到網站後台「資料來源」按「新增銀行」，填入名稱與分頁名稱 → 儲存。

## 管理者後台

右上角「管理者登入」→ 輸入密碼（預設 1234）。後台可以：

- 修改首頁標題、副標題、提示標籤
- 設定試算表網址、每家銀行對應的分頁名稱，並查看每個分頁是否讀取成功
- 查看待補資料（缺網址、疑似誤植、官網查無資料的項目）
- 修改管理者密碼

## 更新程式（GitHub）

到 GitHub 專案頁 →「Add file」→「Upload files」→ 把新版的 `public`、`worker` 資料夾與 `wrangler.toml` 拖進去 → Commit。Cloudflare 會自動重新部署（約 1～2 分鐘）。

## 內建爬蟲

每格放的是官網原句（1～2 句），由 `worker/crawler.js` 的 `RULES` 關鍵字規則挑選。某個項目常挑錯時調整該規則即可。

（選用）在 Cloudflare 的 Worker 設定加入 `GEMINI_API_KEY`（Secret），會改用 Gemini 擷取，摘要更精簡。

## 疑難排解

| 狀況 | 處理方式 |
| --- | --- |
| 顯示「無法讀取後台資料：尚未綁定 KV」 | 確認 `wrangler.toml` 的 KV id 正確，並重新部署 |
| 後台顯示「試算表未開放檢視」 | 試算表共用設定改為「知道連結的任何人都能檢視」 |
| 後台顯示「找不到…欄位」 | 分頁名稱打錯，或表頭欄位名稱不同 |
| 某張卡顯示「抓取失敗」 | 該銀行頁面需要 JavaScript 或擋連線，換成內容直接可見的網址 |
| 忘記管理者密碼 | Cloudflare → Workers KV → CardsCompetitiveAnalysis → 刪除 `admin_pw` 這筆資料，密碼會回到 1234 |
